# SunOS · 从内核到应用的全栈工程

> 一个人维护一台**完全由源码编译**的 Linux 工作站：669 个源码包、597 个组件，从内核、驱动、桌面环境到上层应用，全链路自建。
>
> 日常只做一件事：**让那些装不上、跑不起来、没人支持的东西跑起来。**

## 项目

### [SunOS — 从零源码构建的生产级 Linux 系统](https://github.com/sunboo-00/sunboo-os/blob/main/01-SunOS-%E8%87%AA%E7%BC%96%E8%AF%91Linux%E7%B3%BB%E7%BB%9F.md)

**669 个源码包 · 597 个已安装组件 · 内核 7.2.4 · Qt 6.11 · KDE Plasma 6.7.2**

从 C 运行库和编译器开始，一路编译到桌面环境和生产力应用，并作为日常环境持续运行。六个层次：工具链 → 基础库 → 图形 → 桌面 → 内核驱动 → 应用生态。

### [claude-claw — 自研 AI 编程助手](https://github.com/sunboo-00/sunboo-os/blob/main/02-claude-claw-AI%E7%BC%96%E7%A8%8B%E5%8A%A9%E6%89%8B.md)

**多模型供应商架构 · 162 个可复用技能 · 主动式任务系统**

用统一命名空间管理多家模型后端，一个变量整体切换；带强制行为约束层与跨会话长期记忆系统。

### [515880 跟踪系统 — 把交易分析做成可执行的工程链路](https://github.com/sunboo-00/sunboo-os/blob/main/03-515880%E8%B7%9F%E8%B8%AA%E7%B3%BB%E7%BB%9F.md)

**五层骨架 · 十项铁律 · 25 个核心工具**

每层只回答一个问题，结论强制收缩成四行。核心是**防错设计**——单位分离、术语钉死、主体不可辨、结论收缩，把"人在压力下会自我欺骗"这件事用工程手段堵住。

### [Wine 生产力部署 — Windows 商业软件搬到 Linux 生产使用](https://github.com/sunboo-00/sunboo-os/blob/main/04-Wine%E7%94%9F%E4%BA%A7%E5%8A%9B%E9%83%A8%E7%BD%B2.md)

**证书链修复 · 字体渲染 · 源码级性能修复**

把 Windows 交易终端完整跑在自编译 Linux 上日常使用：修复内嵌浏览器证书链、中文字体渲染，并通过修改兼容层源码消除 50%+ 的 CPU 空转。

### [Cemu / BOTW 工具链 — 模拟器性能补丁与资源工程](https://github.com/sunboo-00/sunboo-os/blob/main/05-Cemu-BOTW%E5%B7%A5%E5%85%B7%E9%93%BE.md)

**单线程 CPU 占用 87.8% → 28%**

用 gdb 采样定位到图形线程的忙等自旋，源码级修复后量化验证；另含游戏资源包解析重打包与跨平台文本迁移工具链。

### [工程问题解决库 — 162 个真实案例](https://github.com/sunboo-00/sunboo-os/blob/main/06-%E5%B7%A5%E7%A8%8B%E9%97%AE%E9%A2%98%E8%A7%A3%E5%86%B3%E5%BA%93.md)
